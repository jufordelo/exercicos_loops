# exercicos_loops
Exercícios para praticar loops em Python 
✅ Lista de Exercícios – Loops em Python (Sem Listas)

🔹Fáceis (1 a 7) – Ideal para treinar lógica e sintaxe básica:
Contar de 1 a 10 usando um laço while.
Contar de 10 a 1 com for (contagem regressiva).
Pedir um número ao usuário e imprimir a tabuada dele de 1 a 10 usando for.
Ler vários números com while até o usuário digitar 0 e somar todos eles.
Ler números até o usuário digitar 0 e imprimir quantos números positivos foram digitados.
Imprimir todos os números pares de 0 a 100 usando for.
Fazer um contador de 0 a 20, mas pular os múltiplos de 4 com continue.


🔸 Intermediários (8 a 14) – Envolvem condições dentro dos loops:
Pedir a idade de várias pessoas e calcular a média das idades. O programa termina com idade 0.
Ler números com while até o usuário digitar 0, e ao final mostrar o maior número digitado.
Criar um menu de opções (ex: 1 - somar, 2 - subtrair, 0 - sair) usando while e break.
Pedir uma senha e só aceitar se for "1234", repetindo com while até acertar.
Pedir um número e verificar se ele é primo com for.
Pedir vários números e contar quantos são múltiplos de 3. Parar com 0.
Contar de 1 a 50, mas parar quando encontrar o número 37, com break.



🔺 Desafiadores (15 a 20) – Misturam tudo e exigem mais atenção:
Criar um jogo de adivinhação de número secreto, usando while e dizendo se o chute é maior ou menor.

Fazer um programa que pede 5 notas e exibe a quantidade de alunos aprovados (nota >= 7).
Imprimir os números ímpares de 1 a 100, mas usar continue para ignorar os pares.
Pedir ao usuário um número N e mostrar a soma de todos os números de 1 até N.
Contar quantos números o usuário digitou antes de digitar dois números seguidos iguais.
