# exercicos_loops
Exercícios para praticar
✅ Lista de Exercícios – Loops em Python

🔹Fáceis (1 a 7) – Ideal para treinar lógica e sintaxe básica: 

1)Contar de 1 a 10 usando um laço while.

2)Contar de 10 a 1 com for (contagem regressiva).

3)Pedir um número ao usuário e imprimir a tabuada dele de 1 a 10 usando for.

4)Ler vários números com while até o usuário digitar 0 e somar todos eles.

5)Ler números até o usuário digitar 0 e imprimir quantos números positivos foram digitados.

6)Imprimir todos os números pares de 0 a 100 usando for.

7)Fazer um contador de 0 a 20, mas pular os múltiplos de 4 com continue.


🔸 Intermediários (8 a 14) – Envolvem condições dentro dos loops:

8)Pedir a idade de várias pessoas e calcular a média das idades. O programa termina com idade 0.

9)Ler números com while até o usuário digitar 0, e ao final mostrar o maior número digitado.

10)Criar um menu de opções (ex: 1 - somar, 2 - subtrair, 0 - sair) usando while e break.

11)Pedir uma senha e só aceitar se for "1234", repetindo com while até acertar.

12)Pedir um número e verificar se ele é primo com for.

13)Pedir vários números e contar quantos são múltiplos de 3. Parar com 0.

14)Contar de 1 a 50, mas parar quando encontrar o número 37, com break.


🔺 Desafiadores (15 a 19) – Misturam tudo e exigem mais atenção:

15)Criar um jogo de adivinhação de número secreto, usando while e dizendo se o chute é maior ou menor.

16)Fazer um programa que pede 5 notas e exibe a quantidade de alunos aprovados (nota >= 7).

17)Imprimir os números ímpares de 1 a 100, mas usar continue para ignorar os pares.

18)Pedir ao usuário um número N e mostrar a soma de todos os números de 1 até N.

19)Contar quantos números o usuário digitou antes de digitar dois números seguidos iguais.
